  operator surface, and B5/BeTenshi are host profiles. Kept historical private
  repository and Vercel slugs so event prep does not manufacture a risky rename.
- Removed localhost-only manager assumptions from deployed routes and applied
  Cloudflare Access headers to the manager path.

  configured tags now say **not installed** and are excluded from the default
  this-machine view.

  memory appears only when the model is actually loaded.

  controls in Requests; filtered dashboard polling from operator history.
- Made production builds use an in-memory DuckDB so a running local console
  cannot make `next build` emit misleading lock errors.
- Added a deterministic event rehearsal and a 15-minute runbook with reset and
  fallback branches.
